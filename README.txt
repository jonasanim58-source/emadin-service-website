EMADIN SERVICE WEBSITE
======================

FILES
- index.html: website content and structure
- styles.css: responsive design and styling
- script.js: mobile navigation and footer year

PREVIEW
Open index.html in a browser. Internet is needed for the Google Fonts to load; the site itself works without them.

PUBLISH FREE WITH GITHUB + RENDER (STATIC SITE)
1. Create a new GitHub repository named emadin-service-website.
2. Upload index.html, styles.css and script.js to the repository root.
3. In Render, choose New + > Static Site and connect the GitHub repository.
4. Set Build Command to blank (or leave the default if Render accepts it).
5. Set Publish Directory to . (a single dot).
6. Create the site. Render will provide a public URL.
